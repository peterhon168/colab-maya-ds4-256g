Maya · Strata Studio 快速接入指南

        
      

      

        

          
1. 无损纳管已有 Colab 实例（推荐）

          
若你在后台已有正在运行的 easycolab G4 会话，请勿重复点击部署。直接点击左侧「🔗 无损纳管已运行会话」，Studio 会以只读方式探测 GPU、/mnt/hf 挂载和 cloudflared 隧道，并将同源代理绑定至 http://127.0.0.1:18766。

        

        

          
2. G4 与加速模式说明

          
    
            
  • Mode B1 (默认推荐)：Shards 1–4 走 HF Xet (~305 MiB/s) 落 NVMe，Shards 5–7 通过 /mnt/hf FUSE3 + HTTP/2 Range 直连，零冷启 GCS 流量；Shard 00002 启用双模阈值 (MAYA_S2_GCS_THRESH=160)。
    • 
            
  • G4 机型防呆：Colab G4 仅支持单规格 Standard (176.9GB RAM)，创建时自动省略 --high-mem。
    • 
            
  • Strata Engine：可直连任意远端/局域网 Strata 服务（如 http://192.168.x.x:18181 或 https://<random-subdomain>.trycloudflare.com）。
    • 
          

        

        

          
3. 隐私保护与安全规范

          
本机凭据一律存放在 $HOME/.config/maya-gcs/（或 /Users/<username>/.config/maya-gcs/）。演示或录屏时请保持右上角「👁️ 录屏隐私打码」开启，自动遮蔽邮箱、隧道域名与 Bucket 名称。
